# Cartella Immagini Piante — Campo dei Fiori

In questa cartella (`public/piante/`) puoi inserire direttamente le fotografie delle piante destinate al catalogo e listino.

## Come usarle nel catalogo

Ogni file salvato qui è accessibile direttamente dall'applicazione tramite il percorso `/piante/nome-file.jpg`.

### Esempio:
1. Salva la foto in questa cartella: `public/piante/bougainvillea-vaso-18.jpg`
2. Nell'area di gestione o nel database/CSV indica come URL immagine: `/piante/bougainvillea-vaso-18.jpg`

## Consigli per le foto in serra:
- **Formato consigliato**: JPG o WebP
- **Risoluzione ideale**: Circa `1200 x 900` pixel (orientamento orizzontale 4:3)
- **Nomi file puliti**: Usa lettere minuscole e trattini, senza spazi né caratteri speciali (es. `gelsomino-grandiflorum.jpg`, `ulivo-alberello-v24.jpg`).
- **Dimensione file**: Se carichi foto direttamente dal pannello `/admin`, l'app le comprimerà in automatico prima del salvataggio!
